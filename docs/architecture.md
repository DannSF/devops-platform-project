# Architecture

## Project Overview

DevOps Platform Project is a hands-on DevOps project designed to demonstrate the complete lifecycle of deploying an application.

The project will progressively evolve from a containerized application into a Kubernetes-based deployment running on AWS and managed with Terraform.
